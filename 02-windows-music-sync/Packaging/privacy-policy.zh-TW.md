# 音樂動態燈光設置：隱私政策

發行者：Tseng
更新日期：2026-10-21

本政策隨程式內建，可在「隱私政策」分頁離線閱讀，不需要開啟外部網頁。

## 播放音訊的處理

使用者按下「開始同步」後，本程式透過 Windows WASAPI loopback 讀取目前預設多媒體播放裝置的混音，在記憶體中計算音量、粗低／中／高頻能量與估測節奏，再產生燈色。混音可能包含 YouTube 及其他應用程式已播放的聲音，並非僅限 YouTube。

本程式不開啟麥克風輸入、不建立錄音檔、不保留原始音訊，也不將聲音、聲紋或音訊分析結果上傳。若其他應用程式將麥克風或通話聲音播放到此輸出裝置，該聲音也可能包含在系統混音中。音訊樣本只在記憶體短暫處理，完成分析後不保存。

## 燈光裝置資訊

本程式透過 Windows LampArray 讀取相符 ESP32-S3 USB Light Strip 的產品資訊、韌體回報燈數及可用狀態，用於辨識裝置、比對設定與處理重新連接。這些資訊不傳送到網路。

App 可設定 1～64 顆，須與韌體回報一致；此範圍不代表已完成 64 顆實體燈條或 USB 供電驗證。預覽變化也不代表已取得實體燈光控制權。

## 本機偏好

正常關閉時，程式會將燈數、配色、效果、速度、靈敏度與亮度保存於目前使用者的本機 settings.json，供下次啟動還原。設定不包含音訊；選擇 Windows 佈景配色時會讀取系統輔色。

偏好檔位於目前使用者 LocalApplicationData 下的 Esp32MusicSync 資料夾；封裝安裝時由 Windows 管理對應位置。使用者可關閉程式後，透過 Windows 檔案管理功能檢閱或刪除此設定檔，之後啟動將使用預設值。

## 選用的本機診斷

只有使用者明確以診斷參數啟動時，程式才會向指定的本機位置寫入測試狀態、音量／頻段／節奏統計、效果設定、燈數、送色與控制權結果、程序資源及關閉清理統計，以及必要的燈光裝置與播放端點描述；不包含原始音訊。

如同時啟用診斷截圖，只保存本 App 的內容畫面，不擷取整個桌面。畫面可能包含本機播放裝置名稱或狀態。診斷檔由使用者管理，可自行檢閱、分享或刪除；本程式不自動傳送這些檔案。

## 網路與第三方服務

本程式本身不建立網路連線，沒有廣告、追蹤器、遙測、雲端帳號或登入功能。

Microsoft Store 與 Windows 可能依其自身規則處理安裝、購買、當機報告或系統診斷資訊；這些平台服務由 Microsoft 管理，不是本程式自行收集或上傳的資料。

## 停止與關閉

使用者可隨時按「停止」停止音訊分析與送色，或以「關閉程式」、視窗 X／Alt+F4、通知區關閉來結束程式並釋放資源。Windows 動態光效設定可管理本程式的燈光控制優先順序。由使用者另存的診斷檔需自行管理。

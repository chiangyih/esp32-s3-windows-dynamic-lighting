# 音樂動態燈光設置：隱私政策草稿

更新日期：2026-10-21。**這是尚未發布的草稿；上架前須填入真實發行者、聯絡方式與公開政策網址，並確認內容符合實際發行版本。**

本程式為 Windows 桌面燈光控制工具。使用者開始同步後，程式透過 Windows WASAPI loopback 讀取目前預設播放裝置的混音，在記憶體中計算音量、粗頻段能量及估測節奏並產生燈色，經 Windows LampArray 介面控制相符的 ESP32-S3／8 顆 WS2812 裝置。播放混音可能包含 YouTube 與其他應用程式的聲音，並非僅限 YouTube。

程式不開啟麥克風輸入、不建立音訊錄音檔、不將聲音、聲紋或音訊分析資料上傳。若其他應用程式已將麥克風或通話聲音播放到這個輸出裝置，該聲音也可能包含在播放混音中。音訊樣本只在記憶體中短暫處理，完成計算後不保留。程式本身不建立網路連線，沒有雲端帳號、廣告、追蹤器或遙測服務。

程式需讀取相符 USB LampArray 裝置的產品資訊與可用狀態，以辨識目前的 8 顆燈條及處理重新插拔。這些資料不傳送至網路。

正常關閉時，程式會將配色、效果、速度、靈敏度與亮度偏好保存於目前使用者的本機設定JSON，供下次啟動還原；不包含音訊。選用Windows佈景配色時會讀取系統輔色。

若使用者明確啟動診斷輸出，程式可能在使用者指定的本機位置寫入測試狀態、音量／頻段／節奏統計、效果設定、送色與控制權結果、程序資源及關閉清理統計，以及必要的裝置／播放端點描述；不包含原始音訊。如另啟用診斷截圖，會保存本 App 的內容區域畫面，可能包含播放裝置名稱與本機狀態，不擷取整個桌面。使用者可自行檢閱與刪除診斷檔。發行版的實際欄位須在發布前核對。

使用者可隨時停止同步或關閉程式，並透過 Windows 動態光效設定管理 App 的控制權。移除 App 可停止其功能；由使用者另存的診斷報告需自行刪除。

Microsoft Store 與 Windows 可能依其各自的隱私政策處理購買／安裝、當機報告或系統診斷資訊；這些服務不由本程式的發行者控制。

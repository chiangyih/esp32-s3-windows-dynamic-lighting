## 產品名稱

音樂動態燈光設置

## 簡短說明

分析電腦播放音訊，讓相容的 ESP32-S3／WS2812 燈條隨音樂變化。

## 說明

讓桌面燈條隨電腦播放的音樂變化。選擇音量、低／中／高頻能量分布或高低音比例，搭配呼吸、流動及單顆依序效果，建立自己的燈光氣氛。

本程式透過 Windows WASAPI 分析預設多媒體播放裝置的系統混音，透過 Windows 動態光效 LampArray 控制燈條。音訊可來自 YouTube 或其他已播放聲音的應用程式；不需登入 YouTube，也不是 YouTube 專用外掛。

使用前必須備妥相容硬體。此版本只控制本專案 ESP32-S3 USB Light Strip 識別的裝置，需搭配正確的 USB HID LampArray 韌體與 WS2812 燈條。App 可設定 1～64 顆、預設 8 顆，設定須與韌體回報一致；App 不會自動偵測實體顆數或改寫韌體。64 顆目前只有程式、預覽與編譯驗證，USB 供電及實體運作仍需依硬體量測確認。

請在 Windows「設定 → 個人化 → 動態光效」啟用裝置，並在背景光源控制項調整本程式的優先順序。開啟 App、確認燈數後，播放音樂並按「開始同步」。不必將 Windows 內建效果切換成「音效」。暫停播放後燈光會漸暗。

選項包含 Windows 佈景主題輔色、彩虹或 2～4 種自訂顏色；速度可使用節奏估測、手動快／中／慢或自訂循環速度。聲頻是粗頻帶分析，節奏可能出現半拍／倍拍，不提供精確音高、FFT 頻譜或自動曲風辨識。

程式採精簡 WinForms 介面，可縮至通知區繼續同步。音訊只在記憶體分析，不開啟麥克風、不保存錄音、不上傳音訊，沒有廣告、追蹤器、雲端帳號或遙測服務。正常關閉會保存本機燈數與燈效偏好；關閉程式會停止分析、釋放控制與視窗資源。隱私政策由發行者 Tseng 提供，在 App 的「隱私政策」分頁內建離線呈現，不需開啟外部網頁。

## 功能欄位

- 自訂 1～64 顆燈數，與相容韌體回報比對。
- 音量、粗低／中／高頻能量或高低音比例變色。
- Windows 輔色、彩虹與 2～4 色自訂配色。
- 呼吸、流動及單顆依序效果。
- 節奏估測、手動曲風快慢及自訂速度。
- 連續色條預覽、通知區執行與明確關閉按鈕。
- 在記憶體分析播放音訊，不錄音、不上傳。

## 硬體與系統需求

- Windows 11 x64；套件最低 23H2，執行時另檢查 LampArray 控制權 API，缺少時會提示更新 Windows；目前以 24H2 測試。
- 本專案 ESP32-S3 USB Light Strip 相容韌體與 WS2812 燈條；一般 WS2812 單獨接 USB 無法使用。
- 符合實際燈數的供電、接線及韌體設定；USB 供電能力需依整板負載量測。
- App 預覽可在沒有硬體時變化，但不代表實體燈光受控制。

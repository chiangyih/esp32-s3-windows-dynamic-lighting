讓桌面燈條隨電腦播放的音樂變化。選擇音量、低／中／高頻能量分布或高低音比例，搭配呼吸、流動及單顆依序效果，建立自己的燈光氣氛。

本程式分析 Windows 預設多媒體播放裝置的系統混音，再透過 Windows 動態光效控制相容燈條。音訊可來自 YouTube 或其他正在播放聲音的應用程式，不需登入 YouTube。

使用前必須備妥相容硬體。此版本只控制本專案 ESP32-S3 USB Light Strip 識別的裝置，需搭配正確的 USB HID LampArray 韌體與 WS2812 燈條。App 可設定 1～64 顆、預設 8 顆，設定須與韌體回報一致；App 不會自動偵測實體顆數或改寫韌體。目前實體原型為 8 顆；64 顆只有程式、預覽與編譯驗證，實體運作及 USB 供電能力仍需依硬體量測確認。

請在 Windows「設定 → 個人化 → 動態光效」啟用裝置，並在背景光源控制項調整本程式的優先順序。開啟 App、確認燈數後，播放音樂並按「開始同步」。不必將 Windows 內建效果切換成「音效」。暫停播放後燈光會漸暗。

配色包含 Windows 佈景主題輔色、彩虹及 2～4 種自訂顏色；速度可使用節奏估測、手動快／中／慢或自訂循環速度。聲頻為粗頻帶分析，節奏估測可能出現半拍／倍拍。

程式可縮至通知區繼續同步。音訊只在記憶體分析，不開啟麥克風、不保存錄音、不上傳音訊，沒有廣告、追蹤器、雲端帳號或遙測服務。正常關閉會保存本機燈數與燈效偏好；關閉程式會停止分析並釋放資源。App 內建可離線閱讀的隱私政策。

系統需求：Windows 11 x64，套件最低 23H2；執行時另檢查所需 LampArray API，目前以 24H2 測試。未連接相容硬體時可觀察預覽，但無法控制實體燈光。

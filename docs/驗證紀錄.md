## USB 實作依據

LampArray descriptor 來源為 Microsoft `ArduinoHidForWindows` commit `deb7e5e20d96bab5571ee2629d634375002f5513`；韌體目錄保留 MIT 授權。針對 ESP32 僅移除 PROGMEM 修飾。[原始 descriptor](https://github.com/microsoft/ArduinoHidForWindows/blob/deb7e5e20d96bab5571ee2629d634375002f5513/src/LampArrayReportDescriptor.h)

本機 Arduino core 相依包 `idf-release_v5.3-cfea4f7c-v1` 的版本紀錄列 TinyUSB commit `249556360`。已核對此版本 HID control callback：Report ID 由底層處理，協定 parser 使用不含 ID 的 payload。短型報告另接受集合最大長度且尾端全為零的 padding。[對應 TinyUSB 實作](https://github.com/hathach/tinyusb/blob/249556360/src/class/hid/hid_device.c)、[Windows Feature report 長度規則](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/hidsdi/nf-hidsdi-hidd_setfeature)
